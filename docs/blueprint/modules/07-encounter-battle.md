# 模块 07：遭遇过场与自动战斗

状态：流程完成，美术统一尚未收口。估算完成度 62%。

## 遭遇流程

```text
袭击倒计时归零
→ 禁止生产与拖拽
→ 暗幕、遭遇徽记、标题与敌人战力
→ 约 680ms 后进入战斗场景
→ 双方入场
→ 行动轨道依次推进
→ 攻击、伤害、受击
→ 胜负表现
→ 胜利返回主场景 / 失败进入结算
```

遭遇徽记已使用固定资产；标题和副标题仍使用临时字体组合，需要统一。

## 战斗场景结构

- 背景复用正式地牢背景并降低饱和/亮度。
- 顶部：战斗标题和当前敌方描述。
- 左右上方：史莱姆与敌人 HP 信息卡。
- 中央：左右角色和各自独立战斗底座。
- 底部：行动轨道、角色头像、当前行动文本、速度按钮和终点剑标。

## 敌人波次

- 第 1 波：木剑见习者，单人。
- 第 2 波：老练猎人，单人。
- 第 3 波起：盾卫、弓手、术士三人小队。
- 后续波次沿用小队阵容，但战力和标题继续增长。

## 行动与胜负

- `getBattlePlan()` 在进入战斗时一次性生成本场回合计划。
- 战力比决定胜率倾向，进化等级提供小幅优势。
- 随机数决定偏向胜者、行动者、伤害浮动和节奏。
- 避免同一阵营无限连动，并在回合过长时推动结果收束。
- `battleSpeed` 支持 1x/2x；每回合 `tempo` 还会改变单次动作时长。

## 行动轨道

- 每名实际参战者有独立头像和进度。
- 当前行动者显示透明高亮框，不再使用会产生白底的占位面板。
- 行动者跑到终点后发动攻击并重置到起点，其他单位同步推进一部分。
- 第一波头像必须是木剑见习者，而非泛用冒险者。

## 攻击表现

- 史莱姆攻击使用固定黏液冲击特效。
- 敌人攻击使用固定武器斩击特效。
- 两张源图朝向不同，`PixelEffects.attack()` 分别计算 flip；不能用同一布尔规则。
- 命中后显示伤害数字、像素碎片、受击动画和轻微抖动。
- 最近一次方向修正仍需在双方各攻击一次的真实预览中复核。

## 验收场景

1. 第一波让敌人先攻击，确认斩击朝向史莱姆。
2. 第一波让史莱姆攻击，确认黏液特效朝向敌人。
3. 第二波验证猎人的 idle/attack/hurt/defeat。
4. 第三波确认三名敌人头像与本体一一对应。
5. 1x 和 2x 各完成一场胜利与失败。
