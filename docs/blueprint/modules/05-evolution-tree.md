## 固定职责边界

程序负责：节点数据、位置、分支关系、Anchor、Junction、连线、四态、购买条件、点击、滚动和裁剪。

固定资产负责：树背景框、节点壳、能力图标、完成按钮、详情按钮和详情面板外观。

## 节点状态

统一四态：

| 状态 | 含义 |
|---|---|
| `owned` | 当前分支至少已购买一级；即使买不起下一级也保持已掌握外观 |
| `available` | 节点已知、前置满足且魂晶足够 |
| `locked` | 节点已知，但前置或魂晶条件未满足 |
| `unknown` | 揭示条件尚未满足，只显示未知图标 |

真实节点内容在前置节点完成后显露，不要求先额外购买一个“揭示节点”。购买条件与揭示条件相互独立。

## 当前树结构

```text
营养 + 产出
└─ 核心蜕变
   ├─ 买一送一
   ├─ 寻骨
   ├─ 合成大骨堆
   └─ 新食物
      ├─ 盐矿
      └─ 池塘

第二骨堆
├─ 大骨
└─ 更好的骨头

染色剂（独立根节点）
```

同一分支的 I/II/III 级在一个节点中逐级购买，不把每一级拆成独立场景节点。

## 布局与连线

- 世界区域：约 1400 × 1080，显示区域约为 `x=104, y=128, w=952, h=440`。
- 当前固定缩放约 0.58，不允许玩家缩放。
- 水平位置固定并居中；只允许垂直滚动。
- 超出可视区的节点和连线由专用 Phaser Camera scissor 裁剪。
- 内容未超过高度时不显示滚动条，也不能空滚。
- 右侧滚动条由代码按可视高度/世界高度计算 thumb。
- 详情面板出现时临时隐藏树专用相机，避免树内容覆盖弹窗。

连线由节点真实尺寸计算 top/bottom Anchor，并通过 `buildVerticalJunction()` 生成共享整数 Junction 和正交线段。美术图内不得包含技能树连线。

## 关键位置关系

- 顶排：营养、产出、第二骨堆、染色剂。
- 第二排：核心蜕变、大骨、更好的骨头。
- 第三排：买一送一、寻骨、合成大骨堆。
- 新食物位于三并排节点的正下方，盐矿和池塘继续向下展开，以便验证滚动裁剪。

具体坐标当前保存在 `showUpgradeTree()` 的 `positions` 对象中，视觉微调应只改该对象和 viewport，不修改连线图片。
