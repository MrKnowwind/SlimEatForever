# 模块 01：核心游戏循环与数值

状态：功能主体完成，数值调优中。估算完成度 82%。

## 核心循环

```text
骨堆/盐矿/池塘产出
→ 玩家拖动食物喂养史莱姆
→ Mass 增长并受形态上限限制
→ 袭击倒计时结束
→ 自动战斗
→ 胜利获得冒险者战利品并进入下一波
→ 失败结算魂晶
→ 永久升级
→ 新一局
```

## 局内状态

- `mass`：本局史莱姆战力与成长值。
- `wave`：当前袭击波次，从 1 开始。
- `itemsFed`：本局吞噬数量，用于结算展示。
- `boneValueBonus`：由“更好的骨头”根据已击败敌人数累积的本局骨头价值加成。
- `bones`：场地中所有可拖动食物，包含骨头、盐、鱼和冒险者战利品。
- `inBattle / isEnded`：控制生产、拖拽和场景流转。

## 永久状态与存档

- 存储键：`slime-dungeon-meta`。
- 存储介质：浏览器 `localStorage`。
- 永久资源：魂晶 `soul`。
- 永久升级字段：营养、产出、第二骨堆、大骨、更好的骨头、染色、核心蜕变、额外产出、寻骨、合成骨堆、新食物、盐矿、池塘。
- 读取时以 `emptyMeta()` 补齐旧存档缺失字段。

## 食物与成长

| 类型 | 基础价值 | 来源 | 当前门槛 |
|---|---:|---|---|
| 骨头 | 6 | 骨堆 | 初始即可吞食 |
| 盐结晶 | 12 | 盐矿 | 当前代码要求 `evolution >= 2` |
| 鱼肉 | 30，池塘Ⅱ后 36 | 池塘 | 当前代码要求 `evolution >= 2` |
| 冒险者 | 90 | 战斗胜利战利品 | 受当前可吞食大小限制 |

食物能否吞食还受 Mass 阶段阈值控制。超过当前形态 Mass 上限时不再增长，食物会返回原位。

## 波次与战斗结果

- 第一波战力 150，此后按约 `1.45^(wave-1)` 增长。
- 第一波倒计时 25 秒；后续波次缩短，最低约 8 秒。
- 战斗不是固定胜负脚本：`mass / enemyPower`、进化等级和随机数共同决定偏向胜者、行动次序、伤害与节奏。
- 胜率限制在 6%–94%，避免完全确定。
- 行动最多约 24 回合，后段会推动预定胜者结束战斗。

## 当前升级效果

- 营养：每级提高骨头价值。
- 产出：缩短骨头生产时间。
- 第二骨堆：增加第二处骨头来源。
- 大骨：增加大骨出现概率及额外价值。
- 更好的骨头：按本局已击败敌人数提高骨头价值。
- 买一送一：概率额外产出骨头。
- 寻骨：允许点击产出容器主动搜索，具有冷却时间。
- 合成大骨堆：两堆合并，显著缩短产出间隔。
- 新食物：开启盐矿和池塘分支。
- 盐矿：提高盐产出速度，三级有额外产出概率。
- 池塘：提高鱼价值并缩短产出间隔。
