# 模块 09：工程状态、测试与交付 QA

状态：基础测试存在，迁移清理和完整视觉回归尚未完成。估算完成度 45%。

## 技术栈

- Phaser 4.0.0。
- Vite。
- 原生 ES Modules。
- Node 内置 test runner。
- Pillow 资产处理脚本。
- 单 Phaser Scene，核心运行时代码主要集中在 `src/main.js`。

## 代码职责

- `src/gameLogic.js`：无 Phaser 依赖的玩法与数值逻辑。
- `src/treeLayout.js`：技能树数学布局函数。
- `src/pixelUiAssets.js`：正式资产注册、主题常量和状态映射。
- `src/pixelArt.js`：固定资产适配、允许的简单程序效果，以及迁移期旧代码。
- `src/main.js`：场景、输入、动画、战斗、结算和进化树编排。
- `scripts/process_pixel_ui_assets.py`：构建期美术后处理。

## 日常验证策略

用户已明确：**不需要每次视觉微调都运行完整 npm 测试。**

按风险分级：

- 仅换 PNG/位置：运行资产处理脚本、PNG/alpha 检查、JS 语法检查、`git diff --check`，再做预览截图。
- 修改资源映射或 SpriteSheet 帧：追加相关资源测试和场景动画检查。
- 修改玩法数值、节点状态、战斗计划：运行相关 Node 测试。
- 阶段收口、合并或发布前：运行完整 `npm test` 和 `npm run build`。

## 阶段完成定义

一个模块只有同时满足以下条件才可标记为完成：

1. 功能逻辑符合对应模块蓝图。
2. 正式美术来自固定资产，允许的动态几何例外有明确理由。
3. 实际预览中无白底、切边、模糊、错误朝向、遮挡和越界。
4. 相关自动检查通过。
5. 旧实现已删除或明确标注为待清理且不可达。
6. 总览与模块文档同步更新。
