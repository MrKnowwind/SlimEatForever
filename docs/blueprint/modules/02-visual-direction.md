## 核心视觉架构

```text
程序：布局、连线、Anchor、Junction、数值、状态、交互、简单粒子
固定资产：角色、敌人、图标、节点壳、正式面板、按钮、道具、场景主体
```

禁止继续让 Phaser Graphics、Canvas rectangle/polygon/line 自由设计复杂正式美术。现存旧代码只能作为迁移期遗留或简单动态反馈，不能作为新资产方案。

## 视觉基准

- 参考对象：当前史莱姆像素密度。
- 世界气质：潮湿、幽暗、略可爱的地牢，而非写实恐怖。
- 主材质：青蓝石材、深海军蓝内底、旧金色金属、少量苔藓绿。
- 角色和可交互物保持高于背景的亮度与饱和度。
- 光源固定来自左上。
- 所有边缘采用硬像素，禁止抗锯齿、模糊和连续渐变。
- 不放随机高光点；高光服务于体积和材质。

## 当前像素主题

`PixelTheme` 当前关键值：

- `uiScale: 4`
- 技能图标显示尺寸：48
- 技能节点显示尺寸：104
- 产出容器显示尺寸：152 × 96
- `assetFilter: nearest`
- outline：1 个逻辑像素
- 连线：1 个逻辑像素基准

运行配置保持：`pixelArt: true`、`antialias: false`、`roundPixels: true`。

## UI 设计语言

- 大框使用完整青蓝石质框，金属只用于角件和强调。
- 普通面板内部尽量留空，让代码排版，不把业务布局烘焙进图片。
- 主按钮、次按钮、树完成按钮和详情按钮必须有不同用途识别，不复用同一张背景充当所有组件。
- 文本层级优先清晰：标题、数据、正文、辅助信息四级即可。
- 中文优先使用统一清晰字体；当前暂用系统中文字体，后续再决定是否引入正式像素中文字体。

## 允许程序绘制的内容

- 技能树连线和 Junction。
- 血条/进度条的动态长度。
- 遮罩与滚动裁剪。
- 命中碎片、尘埃等简单粒子。
- Debug 边界与开发辅助。
- 暂时性的纯色遮罩。
